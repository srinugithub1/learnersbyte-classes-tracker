How attendance is decided

The button opens 30 minutes before a batch's start time. Marking within 15 minutes of the start is ✓Present; after that it is !Late; once the class end time passes the button closes and the day counts as ✕Absent. Only that batch's class days are counted, and only from the day each student joined.
